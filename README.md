# Girls in STEM Network — GitHub Pages

A static website based on the publicly accessible content of the updated Wix homepage and Our Team page (checked November 1, 2026).

## Publish
1. Create a **public** GitHub repository called `YOUR-GITHUB-USERNAME.github.io`.
2. Upload **all** files in this folder to the repository root.
3. In repository Settings → Pages, select Deploy from a branch → `main` → `/ (root)`.
4. Your site should become available at `https://YOUR-GITHUB-USERNAME.github.io`.

## Pages
- `index.html`: Homepage
- `our-team.html`: Team page
- `styles.css`: Shared design
- `script.js`: Mobile navigation

## Important fidelity notes
This is a content-based recreation **not a pixel-perfect Wix export**. The Wix site's actual rendered appearance, typography, spacing, and personal/team photos could not be independently inspected. The team page uses initials placeholders because team photos were not accessible. The event and podcast images load directly from Wix's image servers and might stop loading if Wix changes their URLs. For a truly exact visual reproduction, screenshots of the desktop and mobile site and any original team photos are needed. Other Wix pages and interactive Wix-specific features have not been exported.
